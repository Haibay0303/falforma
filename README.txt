FalForma – CMS-re előkészített változat

A weboldal a data/site.json fájlból olvassa a szerkeszthető tartalmakat.
A .pages.yml a Pages CMS kezelőfelületének mezőit írja le.

Következő lépés:
1. A fájlokat töltsd fel a GitHub falforma repository gyökerébe.
2. Ezután belépünk az app.pagescms.org oldalra GitHub-fiókkal.
